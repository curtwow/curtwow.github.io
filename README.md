三民乙版第一冊 Unit 4 | Word Wheel

使用方式：
1. 直接雙擊 index.html，用 Chrome、Edge 或 Safari 開啟。
2. 字族探索：左右切換核心單字，點字族或 ▶ 可朗讀。
3. 單字總覽：搜尋英文、中文、字族及 Usage。
4. 片語教室：對照句型、例句及學測提醒。
5. 學測挑戰：20 題單選，即時回饋並累計正確率。
6. 上傳 GitHub Pages：將 index.html 放至公開儲存庫根目錄，在 Settings → Pages 啟用 Deploy from a branch，選 main /root。

注意：
- 單字、例句與解析以使用者提供的 Unit 4 講義及先前整合稿整理；每字取代表句，並非出版社單字練習題的完整翻製。
- 學測型試題是教學自編題，並非歷屆真題。
- 發音按鈕使用瀏覽器 SpeechSynthesis，須裝置支援；第三方連結需要網路。
- 33台詞直接搜尋參數和 PlayPhrase 查詢網址可能因平台改版而失效，正式課前請驗證。
- 成績只存在這次開啟頁面的狀態，重新載入會重設。
